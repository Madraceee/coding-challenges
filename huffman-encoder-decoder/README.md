# Huffman encoding and decoding 

Compress and decompress files based on huffman encoding and decoding

#### Usage
`huffman-encoder-decoder compress [INPUT FILE] [OUTPUT FILE]`
`huffman-encoder-decoder decompress [INPUT FILE] [OUTPUT FILE]`

#### Example
```
huffman-encoder-decoder compress test.txt small.bin
huffman-encoder-decoder decompress small.bin test-copy.bin
```
